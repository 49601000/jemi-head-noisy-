# ジェミの頭の中がうるさすぎる｜プロンプト生成コンソール

`index.html` 単体で動作する、なんJスレ風プロンプト生成ツールです。  
元ネタ本文を貼り付けると、Gem などに渡せる「完成プロンプト」を自動生成します。

## 概要

- 形式: 単一HTML（CSS/JavaScript内蔵）
- 目的: 本文を「第三者視点のなんJツッコミスレ」形式に変換するための指示文を組み立てる
- 依存関係: なし（ブラウザのみ）

## 主な機能

- スレタイ接頭辞の選択・自由編集
- 題材名のカスタム指定
- レス数、ツッコミ強度、解説の濃さ、脱線度、メタ視点の調整
- 出力オプション切り替え
  - AA可否
  - 元文引用の多寡
  - `**`（Markdown太字）禁止の明記
  - 要約禁止の強化
  - 日時/IDの有無
  - 雑な決め台詞許可
- 生成結果のコピー
- `.txt` ダウンロード（`jemi_prompt.txt`）
- 埋め込みテンプレート（`basePrompt` / `jemiPrompt`）の確認

## 使い方

1. `index.html` をブラウザで開く
2. 「ここに元ネタ本編テキストを貼る」に入力
3. 左パネルで各種パラメータを調整
4. `プロンプト生成` を押す
5. 必要に応じて `コピー` または `.txt保存` を実行

## 出力仕様（アプリが組み立てる指示）

- なんJスレ形式での出力
- `>>番号` を使ったレス会話構造
- 1レス1ポイント
- 最後に【スレ民による補足】を配置（語数はスライダー指定）
- AI本人としてではなく、スレ民の第三者視点でツッコミ

## ファイル構成

- `index.html`: 本体（UI / スタイル / ロジック）
- `README.md`: この説明ファイル

## 補足

- 初期表示時に `buildPrompt()` が実行され、出力欄に雛形が入ります。
- `source` が空のままでも雛形は生成されます（本文部分はプレースホルダ表示）。

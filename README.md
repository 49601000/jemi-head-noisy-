# ジェミの頭の中がうるさすぎる｜プロンプト生成コンソール

`index.html` 単体で動く、なんJスレ風プロンプト生成ツールです。  
元テキストを貼ると、Gem などに投げるための「完成プロンプト」を生成します。

## 概要

- 形式: 単一HTML（CSS/JavaScript内蔵）
- 目的: 本文を「第三者視点のなんJツッコミスレ」指示に変換
- 依存: なし（ブラウザのみ）

## 主な機能

- スレタイ接頭辞、題材名、レス数、補足語数の調整
- 6スライダーDSL（数値 -> 操作的定義 -> プロンプト文）
  - ツッコミ強度
  - 解説の濃さ
  - 脱線・雑談度
  - メタ視点
  - 元文引用量
  - 要約禁止強度
- ネタ燃料セレクタ（参照元ジャンル制御）
  - おまかせ
  - 野球
  - アニメ
  - ゲーム
  - 時事ネタ
  - ネットミーム
  - 歴史
  - 金融
  - 理系
  - 動物
  - カオスMIX
- プリセット適用
  - 出力例寄せ
  - クソスレカオス
  - 解説控えめツッコミ重視
  - 理解補助寄り
- 出力オプション
  - シンプルAA可否
  - `**`（Markdown太字）禁止
  - 日時ID付与
  - 雑な決め台詞許可
- 生成結果のコピー / `.txt`保存（`jemi_prompt.txt`）
- テンプレート確認（`basePrompt` / `jemiPrompt`）

## スマホ最適化

- iPhoneの入力ズーム対策（入力フォント16px）
- ダブルタップ拡大の抑制（非入力エリアのみ）
- 下部固定のクイック操作バー（生成 / コピー / 出力全画面）
- 「出力欄だけ全画面表示」モード（モバイル時）

## 使い方

1. `index.html` をブラウザで開く
2. 元ネタ本文を貼る
3. スライダーまたはプリセットで調整
4. `プロンプト生成` を押す
5. `コピー` または `.txt保存` を実行

## DSL仕様（実装）

- 定義オブジェクト: `dsl`
- スケール定義: `dsl.scales`
- ネタ燃料定義: `dsl.referenceDomain`
- プリセット定義: `dsl.presets`
- ルール解決: `resolveRule(scale, value)`
- ネタ燃料解決: `getReferenceDomainRule()`

生成プロンプトには `【今回の生成ルール】` セクションが追加され、各スライダーについて次の形式で出力されます。

- `ラベル：値/10（key）`
- 対応する操作的指示文（`prompt`）

さらに `【ネタ燃料】` セクションが追加されます。

- `選択中：ラベル`
- `指示：選択ジャンルの操作的定義`

## 内部構造（単一HTML）

`index.html` は単一ファイルのまま、以下レイヤーコメントで整理されています。

- `HTML UI LAYER`
- `CSS STYLE LAYER`
- `DSL CONFIG LAYER`
- `STATE / EVENT BINDING LAYER`
- `RESOLVER LAYER`
- `PROMPT BUILDER LAYER`
- `UTILITY LAYER`

## ファイル構成

- `index.html`: アプリ本体（UI / スタイル / ロジック）
- `README.md`: この説明

## 補足

- 初期表示時に `buildPrompt()` が実行されます。
- 本文未入力でも雛形は生成されます（本文位置はプレースホルダ）。

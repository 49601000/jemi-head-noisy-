# ジェミの頭の中がうるさすぎる｜プロンプト生成コンソール

`index.html` 単体で動く、なんJスレ風プロンプト生成ツールです。  
元ネタ本文を貼り、各設定を調整して、LLMに渡す最終プロンプトを生成します。

## 概要

- 形式: 単一HTML（CSS / JavaScript内蔵）
- 依存: なし（ブラウザのみ）
- 出力目的: 本文を「第三者視点のなんJツッコミスレ」形式で説明させるための指示文を組み立てる

## 現在のUI構成（操作パネル）

上から以下の順で配置されています。

1. スレタイ接頭辞（固定候補）
2. スレタイ接頭辞（編集可）
3. 題材の呼び名
4. 出力設定
5. 出力パラメータ（折りたたみ）
6. レス数 / 【スレ民による補足】個数
7. ツッコミ強度 / 解説の濃さ
8. プリセット
9. 操作ボタン（生成 / コピー / `.txt保存` / 本文クリア）

### 1) 基本設定

- スレタイ接頭辞（固定候補）を変更すると、編集可入力欄へ反映される
- 最終的に使われる接頭辞は、編集可入力欄（`prefixCustom`）の値が優先される

### 2) 出力設定（モード寄り設定）

- ネタ燃料（ジャンル）
  - おまかせ / 野球 / アニメ / ゲーム / 時事ネタ / ネットミーム / 歴史 / 金融 / 理系 / 動物 / カオスMIX
- チェック項目
  - AIレスバ特化
  - シンプルAA可
  - `**`禁止を明記
  - 日時IDつき
  - 雑な決め台詞許可

### 3) 出力パラメータ（折りたたみ）

`details/summary` で初期は閉じた状態です。

- 脱線・雑談度
- メタ視点
- 元文引用量
- 要約禁止強度

## 本文入力 / 出力パネル

- 本文貼り付け欄（`source`）
- 生成プロンプト表示欄（`output`, readonly）
- 状態表示ピル
  - モード
  - フォーマット
  - 要約圧
  - コピー状態（未コピー / 生成済み / コピー済み）
- 「出力全画面」ボタン（モバイル時のみ有効）

## モバイル操作仕様（重要）

- 画面下部に `mobileActions` 固定バーを表示
  - 生成
  - コピー
  - 出力全画面
- スマホ表示（`max-width:980px`）では本文中の `プロンプト生成` / `コピー` を非表示
- コピー導線
  - 初期状態ではモバイルのコピーは `disabled`（半透明・押下不可）
  - 生成後に有効化される

## プリセット

- 出力例寄せ
- クソスレカオス
- 解説控えめツッコミ重視
- 理解補助寄り

`適用` で各スケール値とネタ燃料を反映し、そのまま生成処理まで実行します。

## 生成ロジックの要点

- `buildPrompt()` が以下を合成
  - `basePrompt`
  - モード別テンプレ（`jemiPrompt` または `genericThreadPrompt`）
  - 現在UI値による `【今回の出力設定】`
  - DSL解決済みの `【今回の生成ルール】`
  - `【ネタ燃料】`
  - 出力形式と注意事項
  - 本文（未入力時はプレースホルダ）

- 6スケールは `dsl.scales` で定義
  - ツッコミ強度
  - 解説の濃さ
  - 脱線・雑談度
  - メタ視点
  - 元文引用量
  - 要約禁止強度

各スケールは「値域 -> `key` -> 指示文（`prompt`）」で解決され、生成文へ展開されます。

## コピー / 保存 / クリア

- コピー: `copyPrompt()`
  - 生成結果が空なら内部で `buildPrompt()` を先に実行してからコピー
- 保存: `downloadPrompt()`
  - `jemi_prompt.txt` として保存
- クリア: `clearSource()`
  - 本文入力欄のみクリア（他の設定値は維持）

## 初期状態

- 起動時に自動生成はしない
- `output` は空
- コピー状態は `未コピー`
- モバイルコピーは無効（生成後に有効化）
